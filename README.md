## 🐍 Python Practice Problems – Strings, Lists, Operators & Dictionaries
This repository contains a collection of beginner-friendly to intermediate Python practice problems focused on strings, lists, operators, and dictionaries.
The exercises are designed to help improve logical thinking, data manipulation skills, and understanding of core Python concepts.

### 📌 Topics Covered
 ✔️ String Operations

String indexing and slicing

Reversing strings

Counting characters

Checking palindromes

Removing duplicates

Splitting & joining strings

✔️ List Operations

Accessing elements with positive/negative indexing

Slicing lists

Nested list operations

Sorting & reversing

List comprehensions

Finding max/min/sum

✔️ Dictionary Operations

Creating dictionaries

Accessing keys & values

Updating and deleting entries

Mapping keys to custom values

Reverse lookup

Frequency counting

✔️ Operators in Python

Arithmetic operators

Logical operators

Comparison operators

Membership operators (in, not in)

Identity operators (is, is not)
